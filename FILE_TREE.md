# Repository map

| Directory | Contents |
|---|---|
| `app/` | Static interactive browser demo, synthetic data, and four Node checks |
| `data/` | Three genuine NYC Parks work-order records, source query, checksum, and refresh script |
| `langflow/components/` | Source for the deterministic review component and native Agent toolset |
| `langflow/exports/` | Five genuine Langflow 1.12 flow JSON files and prepared local project ID; four run without a model |
| `langflow/runs/` | Sanitized API and direct MCP verification reports |
| `langflow/screenshots/` | Genuine local Langflow project, graph, and tool list captures |
| `.bob/` | Project MCP configuration pointing to the local Langflow endpoint |
| `ibm-bob/` | Bob setup, connected-state screenshot, and tool documentation; Bob call remains unverified |
| `demo/` | Synthetic case, presenter script, and 104-second MP4 |
| `docs/` | Pitch deck and supporting PDF documents |
| `design/` | Concept visuals, separate from runtime screenshots |
| `research/` | Secondary references, validation limits, and future interview materials |
| `evaluation/` | Evaluation summary and golden case design |
| `contracts/`, `prompts/` | Proposed schemas and prompts; the main review and Agent policy prompts are wired into Langflow |
| `scripts/` | Prepared Mac launcher for isolated local Langflow |

Start with `README.md`, `IMPLEMENTATION_STATUS.md`, and `SUBMISSION.md`. The native Agent graph has not run without a selected model; do not mistake its prompt or graph for tested AI inference.
