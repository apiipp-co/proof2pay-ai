# Product Roadmap

## Phase 0 - Hackathon validation
- desk research;
- five-user primary interview target if time allows;
- synthetic HVAC golden case;
- problem/solution prototype;
- Bob + MCP + Langflow working path.

## Phase 1 - Hackathon MVP
- structured job/evidence fixture;
- completion intake;
- requirement retrieval;
- requirement-to-evidence mapping;
- deterministic critical blocker logic;
- gap action proposal;
- human approval;
- completion pack draft.

## Phase 2 - Pilot
- real but consented pilot data;
- role-based access;
- versioned requirement templates;
- object storage;
- email/WhatsApp/FSM integrations where permitted;
- evaluation dataset;
- analytics on blockers and cycle time.

## Phase 3 - Commercial product
- multi-tenant SaaS;
- configurable policy engine;
- accounting/FSM/CRM connectors;
- advanced document/image understanding;
- enterprise audit and retention controls;
- multi-branch templates;
- SLA and observability.

## Expansion verticals
HVAC -> CCTV/low-voltage -> IT/network field support -> electrical/building maintenance -> industrial equipment service.
