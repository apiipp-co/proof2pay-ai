# Contributing

1. Create a focused branch: `feat/...`, `fix/...`, or `docs/...`.
2. Never commit secrets, raw customer PII, or real signatures.
3. Label synthetic fixtures and concept designs clearly.
4. Keep AI prompts, business rules, and user-facing claims reviewable.
5. Add/update tests for state transitions and critical blocker rules.
6. Capture genuine implementation screenshots only after the feature works.
7. Open a pull request describing problem, change, test evidence, and risk.
