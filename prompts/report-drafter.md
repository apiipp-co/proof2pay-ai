# Completion Pack Drafting Prompt Spec

Generate a factual draft from verified structured state only.

Do not:
- add unsupported work performed;
- invent customer acknowledgement;
- infer measurements that are absent;
- turn ambiguous evidence into a pass;
- call a document legally accepted unless the configured workflow/human state says so.

Include:
- job metadata;
- verified work summary;
- requirement/evidence table;
- unresolved items;
- evidence index;
- generated-at timestamp/environment metadata.
